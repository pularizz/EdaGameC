# Edalin Game Center

Static red/black game catalog for GitHub Pages.

- 156 game pages
- Global search across every game, not only the current page
- Images on every game card and every game page
- Source-hosted images are used when available; every missing image has a local fallback so no card is blank
- Direct-download button is separate from the Gold-Team source button
- Pagination and genre pages
- Favicon/logo included

Some direct CDN folder names are not publicly verifiable from the supplied source. For those entries the requested `edge15.81.ir.cdn.ir/Online/<game name>/` pattern is used as the direct target; Gold-Team remains a separate source link below it.
